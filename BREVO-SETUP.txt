=====================================================================
  NEWS EMAIL ALERTS - SETUP CHECKLIST
  La Premier Bundesliga Serie A  (lpblsa.vip)
=====================================================================

What you are setting up
  When you push a NEW story in assets/news.js, GitHub automatically
  emails everyone who signed up. Brevo (free plan) does the sending,
  from newsletter@lpblsa.vip.

Nothing on the site changes until STEP 8 - the signup box stays hidden
until you paste in the Brevo form address. It is safe to push the files
first and do the steps below afterwards.

Total time: about 30 minutes. The slow part is Brevo approving your
account and your DNS records taking a while to update (minutes to hours).

Note: Brevo and GitHub rename menus now and then. If a menu name below
does not match your screen, look for the closest one, and if you get
stuck send me a screenshot.

---------------------------------------------------------------------
STEP 0 - Put the files on GitHub
---------------------------------------------------------------------
[ ] Replace your local LPBLSA folder with the one from
    LPBLSA-with-news-alerts.zip (or copy its contents over your folder).
[ ] Commit and push to GitHub as you normally do.

    If GitHub refuses the push and mentions "workflow" or "scope":
    your login is not allowed to add automation files. Fix: on
    github.com, open your repo > Add file > Upload files, and upload the
    .github folder there. (Or sign in again from VS Code / GitHub Desktop
    and allow the "workflow" permission.)

---------------------------------------------------------------------
STEP 1 - Create the mailbox in Zoho
---------------------------------------------------------------------
[ ] In Zoho Mail admin, create a mailbox: newsletter@lpblsa.vip
    (use one of your extra licenses).
    Why: Brevo emails a confirmation code to this address in step 4, and
    people who reply to an alert will reach a real inbox.

---------------------------------------------------------------------
STEP 2 - Create the Brevo account
---------------------------------------------------------------------
[ ] Go to brevo.com and sign up for the FREE plan.
[ ] Fill in the company / website questions (lpblsa.vip, fantasy football
    league). Be honest and specific: it is a private-interest league site.
[ ] Brevo may need to approve your account before it lets you send. You
    can carry on with the other steps while you wait.

---------------------------------------------------------------------
STEP 3 - Create the subscriber list
---------------------------------------------------------------------
[ ] Contacts > Lists > create a list named:  LPBLSA News Alerts
[ ] Open the list and WRITE DOWN ITS ID NUMBER (a number like 3 or 7).
    List ID: ______

---------------------------------------------------------------------
STEP 4 - Authenticate your domain (keeps emails out of spam)
---------------------------------------------------------------------
[ ] In Brevo: Senders, domains & dedicated IPs > Domains > Add a domain
    > lpblsa.vip
[ ] Brevo shows a few DNS records (usually one "brevo-code" TXT record,
    two DKIM records, and a DMARC record). Add each one where your DNS is
    managed. That is usually your domain registrar, or a service like
    Cloudflare if you moved DNS there. Not sure? Look up who you pay for
    lpblsa.vip.

    IMPORTANT:
      - ADD the new records. Do NOT delete or edit your existing Zoho
        records (MX, SPF, DKIM). Your info@lpblsa.vip mail depends on them.
      - If you already have a DMARC record (a TXT record named _dmarc),
        do not add a second one. Keep yours; only add it if none exists.
      - Copy names and values exactly as Brevo shows them. Some DNS panels
        add ".lpblsa.vip" to the name automatically; if so, do not type
        it twice.

[ ] Back in Brevo, click Authenticate / Verify. If it says not found yet,
    wait 15-60 minutes and try again.

[ ] Senders > add a sender:
      Name:  La Premier Bundesliga Serie A
      Email: newsletter@lpblsa.vip
    Brevo sends a code to that address. Open newsletter@lpblsa.vip in Zoho
    and type the code into Brevo.

---------------------------------------------------------------------
STEP 5 - Create the signup form
---------------------------------------------------------------------
[ ] Brevo: Contacts > Forms > create a Subscription form.
[ ] Attach it to the list "LPBLSA News Alerts".
[ ] Keep it to ONE field: email address.
[ ] Turn ON double opt-in (people confirm through an email before they
    are added). This blocks people from signing up other people's
    addresses. Edit the confirmation email text if you like (Spanish is
    fine).
[ ] Save / publish the form.

---------------------------------------------------------------------
STEP 6 - Get the form address and put it on the site
---------------------------------------------------------------------
[ ] Open the form's Share / embed code. Find the text that looks like:

      action="https://xxxxxx.sibforms.com/serve/MUIEA...."

    Copy ONLY the address inside the quotes (from https:// to the end).

[ ] Open the file  assets/alerts.js  and near the top find:

      var FORM_ACTION = '';

    Paste the address between the quotes:

      var FORM_ACTION = 'https://xxxxxx.sibforms.com/serve/MUIEA....';

[ ] Save, commit, and push. After the site refreshes (about a minute),
    the "Alertas por correo" box appears on the home, news and contact
    pages.

---------------------------------------------------------------------
STEP 7 - API key + GitHub settings
---------------------------------------------------------------------
[ ] Brevo: click your name (top right) > SMTP & API > API keys tab >
    Generate a new API key. Name it "github-news-alerts".
    COPY THE KEY NOW - Brevo shows it only once.
    Also in Brevo's security settings: if "Authorized IPs" (IP blocking)
    is switched ON, switch it OFF - GitHub's servers use changing
    addresses and would be blocked.

[ ] GitHub: open your repo > Settings > Secrets and variables > Actions

    Secrets tab  > New repository secret
        Name:   BREVO_API_KEY
        Secret: (paste the key)

    Variables tab > New repository variable
        Name:   BREVO_LIST_ID
        Value:  (the list ID number from step 3)

    Optional variables (only if you want something other than the
    defaults):
        SENDER_EMAIL  default: newsletter@lpblsa.vip
        SENDER_NAME   default: La Premier Bundesliga Serie A
        REPLY_TO      default: info@lpblsa.vip

    Never paste the API key into any file in the repo. The repo is public.

---------------------------------------------------------------------
STEP 8 - Test, in this order
---------------------------------------------------------------------
[ ] A. Sign yourself up with the box on your site. Check your inbox,
    click the confirmation link. Then confirm you appear in the Brevo list.

[ ] B. GitHub repo > Actions tab > "News alert email" > Run workflow:
        story_id:  resumen-de-la-semana   (any id in assets/news.js)
        mode:      dry-run
    When it finishes, open the run and download the "email-preview"
    artifact. Open the .html file in a browser to see the email.
    Nothing is sent in this mode.

[ ] C. Run it again with:
        mode:        test
        test_email:  (your own address)
    Only that address receives the email. It should arrive from
    newsletter@lpblsa.vip. Check the spam folder if you do not see it.
    (A draft campaign named "[TEST] ..." stays in Brevo; delete it
    whenever you like.)

[ ] D. Post a real story the usual way (news writer > download news.js >
    replace assets/news.js > commit and push). Within a few minutes
    everyone on the list gets the alert. The first real send is the true
    test, so it is nice to have yourself on the list.

---------------------------------------------------------------------
IF SOMETHING GOES WRONG
---------------------------------------------------------------------
Open GitHub > Actions > click the failed run > click the red step. The
message says what happened. Common ones:

  "BREVO_API_KEY secret is missing"
     Step 7: the secret name must be exactly BREVO_API_KEY.

  "BREVO_LIST_ID variable is missing or not a number"
     Step 7: it goes on the Variables tab (not Secrets), and only the
     number.

  Brevo answers HTTP 401 / 403
     The API key is wrong, or "Authorized IPs" is on (step 7).

  Brevo mentions the sender / domain not valid
     Step 4 is not finished: the sender must be verified, and the domain
     authenticated.

  "still doesn't show <story-id> after 8 minutes"
     The site did not publish. Check GitHub Pages (repo > Settings >
     Pages) and that the push went through, then run the workflow by
     hand (mode: send, story_id: the story). Tick "force" only if you
     are sure no email went out.

  Signup box shows "Casi listo..." but no confirmation email arrives
     Check spam. Then in Brevo confirm the form is published, attached
     to the right list, and that FORM_ACTION holds the exact address
     from the form's embed code. Try again with a different email.

  Alert email went to spam
     Usually step 4 (DNS) is missing or not verified yet.

  Nothing happened after posting news
     The alert only fires when a story with a NEW id is added. Editing an
     existing story on purpose does not send anything. To send one anyway:
     Actions > News alert email > Run workflow > mode: send.

Limits to remember
  - Brevo free plan: 300 emails per day, and a small "Sent with Brevo"
    footer on each email.
  - Subscriber emails live in Brevo only. Never save them in the repo.

If you are stuck, send me the exact error text from the Actions log (or
a screenshot of the Brevo page), and I will sort it out with you.
