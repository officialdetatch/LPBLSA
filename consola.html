Set up this device

Once, on each device you want to publish from. After that every tool here gets a Publish button.

  1. Put the Consola on your Home Screen first, then open it from that icon and do steps 2 and 3 there.
    • iPhone: Safari → Share → Add to Home Screen.
    • Android: Chrome menu → Add to Home screen (or Install).
    The Home Screen app keeps its own storage, so a key pasted in the browser does not carry over to it.
  2. Make a key on GitHub. Open GitHub →
    • Token name: LPBLSA consola; expiration: up to you (when it runs out, make a new one).
    • Repository access: Only select repositories → LPBLSA.
    • Permissions → Repository permissions → Contents: Read and write. Nothing else.
    • Generate token, then copy it (it starts with github_pat_).
  3. Paste it here.

    The key stays on this device only. It can change files in the LPBLSA repository and nothing else; delete it on GitHub any time and it stops working everywhere.
