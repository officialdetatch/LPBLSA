NBA roster manager

Search a player below and pick an action — draft them off free agency, drop them, bench them, start them, or trade them to another team. "Start at" only lists the spots his positions allow (PG, SG, SF, PF and C need that position, G takes a PG or SG, F takes an SF or PF, UTIL takes anyone), and the snapshot warns you when a roster breaks the rules sheet (9 starters, 5 bench, 1 IR). In the same row you can also edit their Status, FPTS, AVG and LAST directly — click into any of those boxes, type the new number or tag, then click elsewhere (or hit Tab/Enter) to save it. Clear the Status box to remove a tag like DTD once a player is healthy again. When you are done, press Download nba-roster-data.js and drop the file into leagues/nba/assets/, replacing the old one. Nothing changes on the public site until you do. Visitors never see this page unless you send them the link — delete leagues/nba/nba-roster-manager.html and leagues/nba/assets/nba-roster-manager.js before uploading if you would rather it never leaves your computer.
