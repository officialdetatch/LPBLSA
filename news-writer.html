News writer

Write a story as a stack of blocks — paragraphs, subtitles, images and videos, mixed in whatever order you like. Add as many as you want with the buttons below the block list, use the ↑ ↓ arrows to reorder them, and click into any box to edit it directly. For an image or video, upload the file itself into images/ first (an images/news/ folder keeps things tidy) and point the path box at it. Any http(s) link typed into a paragraph — like a Discord invite — becomes a real clickable link automatically, no extra formatting needed. When you are done, press Download news.js and drop the file into assets/, replacing the old one. Pick the League (ALL, NFL, NBA or UCL) first — that decides which section of the News page the story lands in. Nothing changes on the public site until you do. Visitors never see this page unless you send them the link — delete news-writer.html and assets/writer.js before uploading if you would rather it never leaves your computer.
