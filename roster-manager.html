Roster manager

Search a player below and pick an action — draft them off free agency, drop them, bench them, start them, or trade them to another team. In the same row you can also edit their Status, Proj FPTS, AVG and LAST directly — click into any of those boxes, type the new number or tag, then click elsewhere (or hit Tab/Enter) to save it. Clear the Status box to remove a tag like Q once a player is healthy again. When you are done, press Download roster-data.js and drop the file into assets/, replacing the old one. Nothing changes on the public site until you do. Visitors never see this page unless you send them the link — delete roster-manager.html and assets/roster-manager.js before uploading if you would rather it never leaves your computer.
